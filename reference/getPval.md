# Get the p-value

Get the p-value

## Usage

``` r
getPval(x)
```

## Arguments

- x:

  an object from
  [`survival::survdiff()`](https://rdrr.io/pkg/survival/man/survdiff.html)

## Value

the Chi-squared p-value
