# biostatUtil: utility functions for biostatistical projects

biostatUtil provides a wide variety of data analysis, visualization, and
presentation functions used in biostatistical projects.

## Details

This package is currently in development stage while still lacking
comprehensive documentation and testing. The goal is to ultimately
separate biostatUtil into smaller, more cohesive packages each with
better defined purposes.

Functions can be categorized into one of the following:

- Survival analysis

- Character manipulation

- Date manipulation

- Plotting survival-related figures

- Miscellaneous functions
